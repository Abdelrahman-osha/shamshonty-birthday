SHAMSHONTY BIRTHDAY PROJECT

Put this entire folder together with its files. Do not rename the image or audio files.

Required files:
- index.html
- game.js
- birthday.js
- birthday.css
- cinematic-game.css
- song.mp3
- puzzle1.jpg, puzzle2.jpg, puzzle3.jpg
- q2.jpg

Open index.html in a modern browser. The game transitions to the short film after the third puzzle is solved.
The same song.mp3 audio element is looped for the game and film. Browser autoplay restrictions may require the first click/login interaction before audio begins.
